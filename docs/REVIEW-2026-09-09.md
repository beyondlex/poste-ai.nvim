# Code Review — 2026-09-09

Follow-up to `REVIEW-2026-09-06/07/08.md`. Scope: fresh read of the whole
`lua/poste-ai/` tree (stream/session/conversation/window, provider layer,
slash/popup/scope/history/outline, config/commands/health), with special
attention to whether the 09-08 repaint-skip optimization actually works
end-to-end. Baseline: 19 spec files / 169 tests green, luacheck 0 warnings
/ 47 files.

## Bugs fixed

1. **`finalize` overwrote the assistant message's `ts`, defeating the
   09-08 repaint-skip for every completed stream** (`chat/stream.lua`,
   `chat/conversation.lua`) — the conversation buffer stamped the assistant
   block at *begin* of stream (`begin_assistant`), while `finalize` rewrote
   `session_msg.ts` with *end*-of-stream `os.time()`. Any stream longer than
   a second — i.e. every real reply — made `matches_messages` compare
   unequal and forced a full buffer repaint on the next `:PosteAIChat`,
   which is precisely the case the optimization exists for. All message
   records now share one timestamp per turn: the user turn's ts is passed
   into `conversation.append_user`, the assistant session msg takes
   `begin_assistant`'s stored ts, error/cancel blocks render with the
   persisted record's ts, and `finalize` no longer touches `ts`
   (`updated_at`, used for session-list ordering, still reflects the end
   time). Test: stream_spec "keeps session and buffer timestamps aligned
   across a >1s stream" (a 1.1s mock forces the second boundary; the
   pre-fix code fails it).

2. **Bold/italic styling leaked into inline code spans** (`chat/render.lua`)
   — the emphasis scans ran after the inline-code pass but ignored its
   spans, so `` `**not bold**` `` got bold marks and its *literal*
   asterisks were concealed away. Inline-code ranges now fence off the
   emphasis scans (containment check); a bold span containing a code span
   (`**\`code\`**`) is still styled bold. Test: render_spec "treats
   emphasis markers inside inline code as literal text".

3. **Popup width computed from byte length** (`chat/popup.lua`) — CJK
   labels/descriptions are wider than their `#len`, so the palette window
   came out too narrow and clipped their last column. Now sized with
   `strdisplaywidth`.

## Recorded, not changed (with rationale)

- **A `/new` (or `/session`) during the compose window discards the typed
  message entirely** — the input was already cleared, the compose has not
  appended the user turn yet, and the epoch-drop throws the closure away.
  The 09-08 fix deliberately chose this over persisting a half-composed
  exchange; recovery is retyping (Up-arrow history does not have it).
  Fixing it means plumbing the raw text into `force_reset`, which felt
  bigger than the edge.
- **`slash.submit` treats an unknown command with arguments as chat text**
  (`/foo bar` is sent to the LLM; `/foo` alone warns). Looks deliberate —
  arguments make it plausibly a sentence — but surprising; recorded.
- **`resolve_provider` failures are not persisted to the session** — the
  error block renders but vanishes on reopen (adapter errors do persist
  via `finalize`). Transient config errors seem fine as UI-only.
- **`text.truncate` with `limit < 3` returns "..." (3 columns)** — wider
  than the limit. Unreachable from current callers (all clamp to ≥ 4);
  fix only if a caller ever passes smaller limits.
- **API key in curl argv** — carried unchanged from 09-06/07/08; the key
  is never logged (`log.request` records endpoint/model/messages only).
- **`auto_context` 10s guard, `st.cancel` micro-window** — carried from
  09-07/08.
