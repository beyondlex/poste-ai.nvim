# Code Review — 2026-09-08

Follow-up to `REVIEW-2026-09-06/07.md`. Scope: re-read of the streaming
pipeline (`stream.lua`, `session.lua`, `commands.lua`), the provider layer,
and the history/window/slash wiring, with special attention to the
cross-repo contract against poste-db. Baseline: 19 spec files green,
luacheck 0 warnings / 26 files.

## Fixed this round

1. **`/new` and `/session` switches dropped or misplaced an in-flight
   exchange** — neither `commands.new_session` nor `commands.open_session`
   bumped the stream epoch, while `send()`'s compose guard explicitly
   assumed "a force_reset during composition bumps the epoch". Consequences:
   - a switch during the compose window (async mention resolution) let the
     resolved compose proceed against the captured OLD session — its file
     got the user turn + reply while the UI rendered them under the new
     session's name;
   - a switch mid-stream left `finalize` appending the error/cancel note to
     the NEW session's view, and deltas writing into a cleared buffer.
   `stream.force_reset()` now persists what the in-flight exchange already
   accumulated (user turn + partial assistant text) to its owning session
   before discarding, and both switch commands call it up front.
   Test: stream_spec "force_reset persists the in-flight exchange to the
   session it started in".

2. **`:PosteAIChat` repainted the conversation on every invocation** (the
   item recorded in both previous reports) — `open_chat` called
   `set_messages` unconditionally, rebuilding all lines and extmarks. New
   `conversation.matches_messages()` compares the stored render fields
   (role/text/model/ts — the full rendered content) and `open_chat` skips
   the repaint when the buffer already shows this session.
   Test: conversation_spec "matches_messages detects when the buffer
   already shows a message list".

3. **Slash filtering was case-sensitive everywhere** — command names
   (`/New` → "unknown command"), `/session` argument matching, and the
   palette prefix filter all compared exactly. Now case-insensitive,
   including poste-db's `/connections` and `/databases` (same change set
   over there).

## Recorded, not changed (with rationale)

- **API key in curl argv** (`provider/openai.lua`) — unchanged from both
  previous reports; `--header @-` conflicts with `--data-binary @-`, and a
  0600 temp file needs lifecycle handling on every exit path. The key is
  never logged (re-verified: `log.request` records endpoint/model/messages
  only).
- **`M.cancel` no-ops in the window between `busy = true` and the handle
  attach** (`chat/stream.lua`) — microseconds wide; `force_reset` is the
  recovery path for anything wedged.
- **`mention.lua` `cached_list` is never invalidated** — connections added
  to connections.toml mid-session don't appear in `@`-completion until
  restart; deliberate cache, documented in the module docstring.
- **`auto_context`/mention compose window**: `M.cancel()` clearing
  `st.pending` — by design, the 10 s guards guarantee compose runs (carried
  from 09-07).
