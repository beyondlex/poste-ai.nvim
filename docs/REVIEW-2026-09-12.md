## Bugs fixed

1. **Byte-budget truncation split multibyte characters**
   (`provider/openai.lua` `error_from_body`, `chat/mention.lua` file
   blocks) — the 300-byte cap on provider error messages cut `sub(1, 300)`,
   which lands mid-character for CJK error bodies (DeepSeek/Qwen are
   first-class providers here and answer in Chinese), notifying invalid
   UTF-8. The 8000-byte cap on @file context blocks had the same cut and
   sent invalid UTF-8 to the provider. Both now go through a new
   `text.utf8_safe_cut`, which backs the boundary off continuation bytes
   while keeping the byte budget. Tests: utf8_safe_cut suite (new
   `text_spec.lua`) + a CJK error-message case.

## Feature

2. **`:PosteAISessionDelete [id]` — sessions were accumulate-only** —
   `session.delete(id)` existed with no user-facing entry point, so session
   files piled up under `poste-ai/sessions/` forever and cleaning them
   meant deleting files by hand. The command picks a session
   (vim.ui.select, same formatting as `:PosteAISessions`) or takes an
   explicit id, asks for a `y` confirmation, then deletes. When the deleted
   session is the one currently shown, the view resets like `/new` (scope
   cleared, ready note); the stale pointer is tolerated since `load_last`
   falls back to a fresh session on the next `current()`. Tests: current-
   session delete falls forward cleanly, sibling delete leaves the current
   session intact (new `commands_spec.lua`).

## Recorded, not changed (with rationale)

- **`resolve_all`'s 10s per-ref timeout holds `st.pending` until it
  fires** — carried: by design, a hung mention resolver must not wedge
  sends forever.
- **`text.truncate` with limit < 3 returns "..." wider than the limit** —
  carried from 09-06; no caller passes such limits.
- **slash command filtering stays prefix-based** (sessions got substring
  matching in 09-11 because the list grows) — commands are a short fixed
  list; carried.
- **`popup.close()` keeps `st.buf` alive for reuse** — intentional
  (create-once reuse), matches the window.lua buffer pattern.
- **`window.apply_input_keymaps` maps `<C-n>` for new_session while the
  popup owns `<C-n>` while open** — safe by construction: the popup's
  temporary maps shadow and are restored on close.
- Carried unchanged from 09-06/07/08/09/11: `/new` during compose discards
  the typed message; unknown slash command with args is sent as chat text;
  API key in curl argv (never logged); `session.list()` decodes every file.
