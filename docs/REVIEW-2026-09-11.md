Follow-up to `REVIEW-2026-09-06/07/08/09.md`. Scope: fresh read of the
whole `lua/poste-ai/` tree — stream/openai/sse (send pipeline, job

session/scope/outline, config/commands/health/context_api. Baseline:
20 spec files / 171 tests green, luacheck 0 warnings / 48 files.

## Bugs fixed

1. **Code-block execution rendered result blocks with a second
   timestamp** (`chat/actions.lua`) — the exec-note, error and note
   blocks called `conversation.append_note/append_error` without a ts
   while `session.append_record` stamped its own `os.time()`: across a
   second boundary the buffer block and the persisted record diverged
   and `matches_messages` forced a full conversation repaint on
   reopen — the exact class the 09-08/09-09 alignment fixes covered
   for the stream paths. Every render now reuses its session record's
   ts. Test: error path pairs `session.ts` with the stored buffer
   message ts.

2. **A reversed @file line range produced an empty context block**
   (`chat/mention.lua`) — `@file(50-10)` was clamped as-is into
   `vim.list_slice(lines, 50, 10)` → empty. Ranges are now swapped
   before slicing (`range_mention` already normalized this way).

## Improvement

3. **`/session` completion matches name substrings** (`chat/slash.lua`)
   — sessions default to `chat YYYY-MM-DD HH:MM`, so the word a user
   filters by sits mid-name and the prefix-only match found nothing.
   Substring matching keeps prefixes working. Test: mid-name word
   matches, non-match stays empty.

## Recorded, not changed (with rationale)

- **`resolve_all`'s 10s per-ref timeout leaves `st.pending` held until
  it fires** — by design: a hung mention resolver must not wedge sends
  forever, and the epoch check drops a late compose correctly.
- **`clean_token` keeps trailing `)`** — needed for line-range refs; a
  plain `@file.lua)` in prose therefore fails to resolve and renders
  "(unavailable)" instead. Rare; cosmetic failure direction.
- **slash `find_command` is case-insensitive but command-name filtering
  stays prefix-based** — commands are a short fixed list; sessions (the
  growing list) got the substring treatment instead.
- **`session.list()` reads and JSON-decodes every session file** to
  count messages — fine at real-world session counts; a shared index
  would be over-engineering.
- Carried unchanged from 09-06/07/08/09: `/new` during compose discards
  the typed message; unknown slash command with args is sent as chat
  text; `resolve_provider` failures stay UI-only; `text.truncate` with
  limit < 3 returns "..." wider than the limit; API key in curl argv
  (never logged).
